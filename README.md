# Односторінковий сайт автобусних перевезень

## 1. Фото (обов'язково перед запуском)
Покладіть у папку `img/` (JPG, до 300 КБ кожне, ширина 1600 px):
- `hero.jpg`: головний екран (автобус на дорозі)
- `about.jpg`: блок «Про компанію»
- `g1.jpg … g6.jpg`: галерея (автобус зовні, салон, сидіння, місто, дорога)

Беріть власні фото або безкоштовні з ліцензією на комерційне використання (Unsplash, Pexels). Якщо файла немає, блок не показується (порожніх рамок не буде), але з усіма фото сайт виглядає значно краще.

## 2. Telegram
1. `cp .env.example .env`, впишіть `TELEGRAM_BOT_TOKEN` і `TELEGRAM_CHAT_ID`.
2. Додайте бота в групу, дайте право писати. Chat ID групи має вигляд `-100…`.
3. Перевірка: `node check-telegram.js`. Бот напише в групу тестове повідомлення. Якщо ✅, усе працює.

## 3. Публікація на сервері (VPS, Ubuntu)
```
sudo apt install -y caddy nodejs npm        # потрібен Node 18+
# скопіюйте папку проєкту в /opt/bus-landing
cd /opt/bus-landing && cp .env.example .env && nano .env
sudo npm i -g pm2 && pm2 start server.js --name landing && pm2 save && pm2 startup
```
Файл `/etc/caddy/Caddyfile` (HTTPS підключиться автоматично):
```
ваш-домен.ua {
  reverse_proxy localhost:3000
}
```
Потім `sudo systemctl reload caddy`. У DNS домену додайте A-запис на IP сервера.
Render.com / Railway: Web Service, команда запуску `node server.js`, змінні TELEGRAM_* додайте в налаштуваннях сервісу.

## 4. Реклама
- Meta Pixel: вставте ID у константу `PIXEL_ID` на початку `<script>` в `index.html`. Подія `Lead` спрацює після успішної заявки.
- Заявки також зберігаються в `data/leads.jsonl`. Невідправлені в Telegram повторюються автоматично щохвилини.

## 5. Відгуки
20 відгуків в `index.html` (масив `R`) демонстраційні, над слайдером є позначка. Після заміни на справжні видаліть абзац з класом `note`.
